Put royalty-free music tracks here, in mood folders:

  mythic/   epic or devotional, for mythology stories
  calm/     gentle, for folk tales and science
  tense/    suspenseful, for dramatic moments
  festive/  celebratory (Diwali etc.)
  upbeat/   energetic, for the simulation reels
  chill/    relaxed

Good free sources that allow use in monetised videos:
  - Pixabay Music (pixabay.com/music): no attribution needed
  - YouTube Audio Library (YouTube Studio > Audio Library): check each track's licence;
    if it says attribution is required, save the credit line in a .txt file with the
    same name as the track (e.g. "Track.mp3" and "Track.txt").

Formats: mp3, wav, ogg, m4a, flac. A reel picks one track per seed from the folder named by
its music style; if a folder is empty, generated music is used instead.
